#
# 格式：每行「路徑樣式  類別」。# 開頭是註解。
#   *  比對一層目錄內的任意字元；** 可跨目錄；結尾是 / 表示整個目錄。
#   一個路徑符合多行時，以最後一行為準。
#
# 類別與規則：
#   ruling     裁決          任何修改都要修法紀錄；刪改既有內容會另外標示
#   spec       規格          任何修改都要修法紀錄
#   gate       閘門          任何修改都要修法紀錄
#   tradition  給 AI 的指示  任何修改都要修法紀錄
#   baseline   凍結基線      只刪除行的修改免修法；新增或改寫行、刪除整個檔案要修法紀錄
