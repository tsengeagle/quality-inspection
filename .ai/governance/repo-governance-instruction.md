## Purpose

This file is the repo-level governance entrypoint for frontend MFE work under the aligned `.ai/governance/` structure.

## Frontend MFE Routing

For frontend MFE implementation tasks:

1. Read [`frontend-ui.instructions.md`](./frontend-ui.instructions.md) first.
2. Use [`frontend-mfe-governance.md`](./frontend-mfe-governance.md) for shell boundary, contract, standalone mode, and asset ownership rules.
3. Use [`frontend-design-language-mfe.md`](./frontend-design-language-mfe.md) for page composition, tabs, tables, empty states, loading, modal boundaries, and styling rules.
4. Use [`frontend-mfe-decisions-r1.md`](./frontend-mfe-decisions-r1.md) for R1 decision rationale and back-merge context.
5. Use [`authority-sources.md`](./authority-sources.md) when you need broader baseline references.
