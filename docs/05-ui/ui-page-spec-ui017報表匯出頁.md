# UI Page Spec v1

## UI-017 報表匯出頁

> 依據：decision-log D-056（請求格式以程式為準）、D-057（依案件建立時間過濾、區間必填、逐案資料列分頁）、D-055 第 6 點（逐案分數遮罩）、D-042／D-047（院區範圍）；api-spec 15.1、15.2。
> 呈現方式、檔案格式與預設區間依負責人 2026-11-17 的裁決：分頁表格＋下載檔案、CSV（UTF-8 加 BOM）、預設上一個整月。

---

## 1. 頁面基本資訊

### Page ID
`UI-017`

### 頁面名稱
報表匯出頁

### 頁面目的
依日期區間查詢「審查完成」報表：在頁面上以分頁表格預覽逐案資料與統計摘要，並可下載整個區間的 CSV 檔。

### 頁面型態
`Action`（條件查詢＋匯出）

### 對應 IA 模組
`查詢與報表`

### 對應主要角色
- `HOSPITAL_MANAGER`
- `AUDITOR`
- `SYSTEM_ADMIN`（逐案資料列只有 metadata，沒有分數與專案，D-100）

### 不開放角色
- `REVIEWER`
- `REREVIEWER`

### 對應主要 API
- `POST /reports/export`（api-spec 15.2）

### Route 與模組
- Route：`/reports/export`
- Feature module：`features/reports`（lazy-loaded，與 `cases`、`sampling` 同層）
- 角色 guard：只允許上列三個角色；其他角色導到既有的 forbidden 呈現。

---

## 2. 頁面責任範圍

本頁負責：
- 輸入報表類型、日期區間，以及 `SYSTEM_ADMIN` 才有的院區條件
- 呼叫匯出 API，呈現當頁逐案資料列、分頁與統計摘要
- 下載整個區間的 CSV 檔

本頁不負責：
- 判斷哪些分數要遮罩：完全以 API 回傳的 `maskedFields` 為準，前端不自行推論
- 院區範圍的授權：由後端依 D-042／D-047 決定，前端只呈現 scope 摘要
- 儀表板（UI-015）與稽核查詢（UI-016）

---

## 3. 頁面主要區塊

### 3.1 條件區

| 欄位 | 說明 |
|---|---|
| 報表類型 | 下拉選單，目前只有「審查完成」（`REVIEW_COMPLETION`），預設選取。 |
| 日期區間 | 起日、迄日兩個日期欄位，**必填**。畫面上的迄日為「含當天」；送出時轉換見 §4。 |
| 院區 | 只有 `SYSTEM_ADMIN` 顯示，可留空表示全部院區。其他角色不顯示，scope 摘要寫明「本院」。 |

- 預設區間：上一個整月。例如今天是 2026-11-17，起日 2026-10-01、迄日 2026-10-31。
- 起日晚於迄日時，查詢與下載按鈕停用，並在欄位旁提示。
- 操作：「查詢」載入第 1 頁；「下載 CSV」見 §5。

### 3.2 Scope 摘要

顯示目前條件：報表類型、日期區間（含迄日當天）、院區範圍（`SYSTEM_ADMIN` 為所選院區或「全部院區」，其他角色為「本院」）。

### 3.3 統計摘要

顯示 API 回應的 `summary`：總案件數、已結案數、有複審數、逾期數、完成率、複審率、逾期率。摘要以整個日期區間計算，不受分頁影響，並與 `totalElements` 對應同一個母體（D-057 第 3 點）。

### 3.4 逐案資料表格

| 欄位 | 來源 | 顯示 |
|---|---|---|
| 案件 | `caseId` | |
| 專案 | `projectId` | |
| 院區 | `hospitalId` | |
| 狀態 | `status` | 沿用案件列表的狀態文字 |
| 初審醫師 | `reviewerId` | |
| 複審醫師 | `rereviewerId` | 空值顯示「—」 |
| 初審分數 | `initialScore` | 若 `maskedFields` 含 `initialScore`，顯示「已遮罩」 |
| 最終分數 | `finalScore` | 若 `maskedFields` 含 `finalScore`，顯示「已遮罩」 |
| 建立時間 | `createdAt` | UTC 時間點（`Instant`），畫面固定以 `Asia/Taipei` 顯示（D-075 第 5 點），不依瀏覽器的時區 |
| 結案時間 | `closedAt` | UTC 時間點（`Instant`），與 `createdAt` 相同的呈現方式（D-075 第 6 點）；空值顯示「—」 |

- **被遮罩的分數不得顯示為 0、空白或「—」**，一律顯示「已遮罩」，與「沒有分數」區分（api-spec 15.2）。
- **metadata 形狀（D-100）**：`SYSTEM_ADMIN` 拿到的每一列沒有 `projectId`、`initialScore`、`finalScore`、`maskedFields`。表格不顯示「專案」「初審分數」「最終分數」三欄（不是顯示「已遮罩」）。依回應的形狀判斷，不依角色：資料列沒有 `maskedFields` 這個欄位就是 metadata 形狀。沒有資料列時分不出形狀，也不需要分（表格是空的）。
- 分頁：每頁 100 筆（API 預設），顯示 `page`、`totalPages`、`totalElements`；依 `caseId` 遞增排序，前端不另外排序。

---

## 4. 日期區間的轉換

- 日期欄位是 `Asia/Taipei` 的日曆日期，不依瀏覽器的時區（D-077 第 1 點）。
- 送出時：`from` ＝ 起日 00:00 `+08:00`；`to` ＝ 迄日的**次日** 00:00 `+08:00`；兩者以 UTC 時間點（`Z`）送出。這對應 API 的含起不含迄，畫面上的迄日因此包含當天。
- 預設區間「上一個整月」以台北的今天計算（D-077 第 2 點）。
- 例：起日 2026-10-01、迄日 2026-10-31 → `from=2026-09-30T16:00:00Z`、`to=2026-10-31T16:00:00Z`。

---

## 5. 下載 CSV

### 5.1 取資料
- 以目前條件逐頁呼叫 API（`size=1000`，從第 0 頁到 `totalPages - 1`），依序串接資料列。
- 若任何一頁回傳的 `totalElements` 與第一頁不同，表示下載期間資料有變動：中止下載、不產生檔案，提示「資料在下載期間有變動，請重新下載」。
- 下載進行中顯示進度（已取得頁數／總頁數），並停用條件欄位、查詢與下載按鈕；任一頁失敗即中止，不產生不完整的檔案。

### 5.2 檔案格式
- 編碼 UTF-8，檔頭加 BOM（讓 Excel 正確顯示中文）；換行 CRLF；欄位以逗號分隔，依 RFC 4180 用雙引號包住含逗號、雙引號或換行的值。
- 第一列為欄位標題，順序與 §3.4 表格相同，使用相同的中文標題。metadata 形狀時同樣沒有「專案」「初審分數」「最終分數」三欄（D-100）。
- 被遮罩的分數寫入「已遮罩」；`null` 寫入空字串。
- `createdAt` 寫入 ISO-8601 UTC（例如 `2026-10-02T01:00:00Z`），避免檔案內容隨開啟者的時區改變。
- `closedAt` 與 `createdAt` 相同，寫入 ISO-8601 UTC（例如 `2026-10-05T01:30:00Z`），標題為「結案時間」（D-075 第 6 點）。
- **防公式注入**：值以 `=`、`+`、`-`、`@`、Tab 或 CR 開頭時，前面加一個單引號 `'`。
- 檔名：`review-completion_{起日}_{迄日}.csv`（日期為畫面上的台北日期，迄日含當天），例如 `review-completion_2026-10-01_2026-10-31.csv`。
- 統計摘要不寫入 CSV；CSV 只含逐案資料列。

## 6. 頁面狀態

| 狀態 | 呈現 |
|---|---|
| 初始 | 帶入預設區間，尚未查詢；表格區顯示「請按查詢」。 |
| 載入中 | 條件區與按鈕停用，表格區顯示載入狀態。 |
| 有資料 | 顯示 scope 摘要、統計摘要、表格與分頁。 |
| 無資料 | `totalElements = 0`：統計摘要照常顯示（全為 0），表格區顯示「此區間沒有案件」，下載按鈕停用。 |
| 請求錯誤 | `400`：顯示後端回傳的訊息（例如日期區間不合法）。其他錯誤：顯示「查詢失敗，請稍後再試」，保留條件。 |
| 無權限 | 角色不符或 `403`：沿用既有的 forbidden 呈現。 |

---

## 7. 權限與可見性

- `HOSPITAL_MANAGER`、`AUDITOR`：只看本院（D-042）；不顯示院區欄位。逐案分數是否遮罩依 `maskedFields`。
- `SYSTEM_ADMIN`：可選院區或全部院區（D-047）；逐案資料列是 metadata 形狀（§3.4），畫面與 CSV 都沒有專案與兩個分數的欄（D-100；原本是顯示「已遮罩」）。
- 前端不得以任何方式補回被遮罩的值，也不得快取遮罩前的資料（D-033）。

---

## 8. 頁面測試重點

1. 預設區間為台北的上一個整月；迄日含當天，送出的 `to` 為迄日次日 00:00 `+08:00` 的 UTC 時間點。瀏覽器不在 UTC+8 時結果相同。
2. 起日晚於迄日時，查詢與下載停用。
3. 被遮罩的分數在表格與 CSV 都顯示「已遮罩」，不顯示為 0 或空白。
4. 分頁資訊與統計摘要依 API 回應呈現；換頁只換資料列，不重算摘要。
5. 下載 CSV 會逐頁取完，含 BOM、標題列與 RFC 4180 跳脫；以 `=`、`+`、`-`、`@` 開頭的值加單引號。
6. 下載期間 `totalElements` 變動、或任一頁失敗時，中止且不產生檔案。
7. `SYSTEM_ADMIN` 才顯示院區欄位；其他角色的 scope 摘要為「本院」。
7a. metadata 形狀的回應：表格與 CSV 沒有「專案」「初審分數」「最終分數」三欄（D-100）。
8. `REVIEWER`、`REREVIEWER` 無法進入本頁。

---

## 9. 不屬於本頁處理的事項

- 其他報表類型：目前 API 只支援 `REVIEW_COMPLETION`。
- Excel（.xlsx）或 PDF 匯出。
- 依案件建立時間以外的時間欄位篩選（D-057 第 1 點只定義建立時間）。
- 儀表板（UI-015）。
