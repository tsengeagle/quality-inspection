# 待裁決（iccard-signing 試寫）

### Q-01 開處方時卡號不符，簽章情境要不要撤銷？

白板 03 頁寫「卡片不符 → 回到 UC-I1 重新驗卡」，設計文件 §6.4 寫「不符就要求重新驗卡」。兩處都沒說記住的 PIN 是否清除。

- 撤銷：下一次開處方回「尚未設定簽章方式」，不會再送 PIN。
- 不撤銷：換回原本的卡就能繼續開處方。

範例 `card_mismatch_at_signing_asks_to_verify_again` 的 `observe` 要寫出其中一種。

### Q-02 簽章情境的期限多長？

到期撤銷是既有行為（spec 022 的範圍）。範例要用 `advance` 讓時間超過期限，必須知道長度，或由規格目錄的預設設定值提供。
