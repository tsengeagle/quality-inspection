# 待裁決（card-gate 試寫）

### Q-01 關閉模組失敗時，總共呼叫幾次關閉？

設計文件 §6.3 寫「間隔短暫時間重試，最多三次」，白板 02 頁寫「重試三次仍失敗」。範例要寫出 `calls` 的完整序列，所以必須決定：

- 第一次加重試三次，共 4 次；或
- 總共 3 次。

「間隔短暫時間」的長度也未定。若以時鐘控制，範例要寫 `advance`。

### Q-02 沒有登入時，清理要不要呼叫 CloseSession？

§6.3 的流程是 `finally: CloseSession → CloseModule`。卡號不符時沒有登入（session 為 0），是否仍呼叫 `CloseSession`，設計文件沒有說。範例的 `calls` 要寫出完整序列，必須決定。
